Connect your AI

Works with your AI

Ask your AI when to move the turkey to the fridge. It counts back from your dinner hour and your bird's weight: a computed answer, not a guess.

Connect this site to Claude, Cursor, or any other MCP client (MCP, the standard way AI apps connect to outside tools). It is free, and it takes about a minute.

1. Copy the server address

https://mcp.thawday.com/mcp

2. Add it to your AI

Claude Code: one command 
claude mcp add --transport http thawday https://mcp.thawday.com/mcp
Claude Desktop or Cursor: paste into the MCP settings 
{
  "mcpServers": {
    "thawday": {
      "url": "https://mcp.thawday.com/mcp"
    }
  }
}

3. Ask your AI: “My turkey is 14 pounds and dinner is Thursday at 4. When should it go in the fridge?”
